Rust Systems Fundamentals 🦀

A beginner-friendly introduction to **Rust programming**, focused on systems-level fundamentals such as memory safety, ownership, and performance.

This repository is designed as a **hands-on learning guide** for developers who want to understand how Rust works under the hood while building a strong foundation for systems programming.

---

## 🎯 Goals

- Learn Rust from first principles
- Understand Rust’s ownership, borrowing, and lifetimes model
- Write safe and performant systems-level code
- Build confidence reading and writing idiomatic Rust

---

## 📚 What You’ll Learn

- Rust toolchain (`cargo`, `rustc`)
- Variables, types, and control flow
- Ownership, borrowing, and lifetimes
- Structs, enums, and pattern matching
- Error handling with `Result` and `Option`
- Modules and project structure
- Basics of memory safety and zero-cost abstractions

---

## 🛠️ Prerequisites

- Basic programming experience (any language)
- Git installed
- Rust installed
